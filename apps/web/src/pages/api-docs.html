API

API status

Toolpad's REST API is not available on toolpad.in yet. Every tool on this site runs in your browser, so you can use them without it.

Current status

Requests to /api/v1 on toolpad.in do not reach an API server, so the examples that were previously on this site will not work. We have not published a date for a public API. This page will be updated when that changes.

Use the tools in your browser instead

Each tool below does the same job as the endpoint it replaces, and needs no sign-up or key.

  • Test name generator for realistic names, including Indian regional pools.
  • Full profile generator for a test person with name, date of birth, contact details and address.
  • Test address generator for US, UK and India addresses.
  • UUID generator for RFC 4122 v1 and v4 identifiers, up to 1000 at once.
  • IP address generator for public, private, IPv4 and IPv6 addresses.
  • JSON formatter for pretty-printing, minifying and validating JSON.
  • JSON to XML and XML to JSON for converting between the two formats.
  • JSON to CSV and CSV to JSON for spreadsheet data.
  • Base64, hex and URL encoders and decoders.

Questions about the API

For questions about a future API, use the contact page.

Why this page changed

Earlier versions of this site listed API examples on many tool pages. Those examples did not work on toolpad.in, because no API server was running there. They have been removed, and this page now describes the current position.

Frequently asked questions

Can I call the tools from my own code?

Not yet. The tools are built to run in a browser. If you need the same output in a script, you can reproduce the rules described on each tool page, or use a library that implements the same format, such as a standard JSON or XML parser.

Will the API be published?

We have not announced a date. Any future API will be documented on this page before it is switched on.
