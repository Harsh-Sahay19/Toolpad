About DOCX to PDF conversion

This tool converts Microsoft Word (.docx) files to PDF. Files are sent to our server, converted, and returned as a download. The original file is deleted immediately after conversion — no content is stored or logged.

Is my document kept private? +
Yes. Files are deleted immediately after conversion. No content is stored or logged.
What is the maximum file size? +
Files up to 10MB are supported.
Does it support .doc format? +
Only .docx is supported. Open .doc files in Word or LibreOffice and save as .docx first.
