XML formatter

Format, minify and validate XML. Errors show the first problem the parser finds. Everything runs in your browser.

Runs in your browser

Format XML

What the formatter does

  • Format indents nested elements by two spaces, so the structure is easy to read.
  • Minify removes indentation and whitespace between elements.
  • Validate checks that the XML is well-formed and reports the first error with its message.

Example

<root><item id="1">Alpha</item><item id="2"/></root> <root> <item id="1">Alpha</item> <item id="2"/> </root>
