IMSI generator

Test data only

Generate 15-digit IMSI (International Mobile Subscriber Identity) numbers using real MCC-MNC operator codes. Supports major carriers across the US, India, UK, and Australia. For telecom software testing only.

What this IMSI generator does

The generator creates 15-digit IMSI (International Mobile Subscriber Identity) values. Each one starts with a mobile country code and a mobile network code taken from the countries listed on the page, followed by random subscriber digits. Use the output as realistic input for telecom test systems, provisioning scripts and databases.

Generated IMSIs are not assigned to any SIM card or subscriber. They are test data.

How to use it

  1. Choose a country: United States, India, United Kingdom, Australia, or all countries.
  2. Choose how many IMSIs to generate.
  3. Click Generate, then copy the values or download the CSV.

How an IMSI is built

  • MCC (3 digits): the mobile country code, for example 404 for India or 310 for the United States.
  • MNC (2 or 3 digits): the mobile network code, which identifies the operator within that country.
  • MSIN (the remaining digits): the mobile subscriber identification number, unique to each subscriber within the network.

The IMSI is stored on the SIM. It is used inside the operator's network and is not normally shown to the subscriber. Your phone number (MSISDN) is a separate identifier, linked to the IMSI by the operator's subscriber database.

IMSI, IMEI and ICCID

An IMSI identifies the subscriber. An IMEI identifies the handset, so the same IMEI stays with a phone when the SIM changes. An ICCID identifies the SIM card itself. Test systems often need all three, and each one should be generated separately.

Limits and responsible use

  • A generated IMSI cannot be used to identify a real subscriber or to place calls.
  • Do not use real subscriber identifiers in test data, and do not try to use an IMSI to access another person's account or SIM.
  • Operator codes change over time. Check the MCC and MNC values against an official list before you rely on them for anything beyond testing.

What is an IMSI number?

An IMSI (International Mobile Subscriber Identity) is a unique 15-digit number that identifies a mobile subscriber within a cellular network. It is stored on the SIM card and is distinct from the phone number — the IMSI identifies the subscriber to the network, while the phone number (MSISDN) is what others dial.

IMSI structure

  • MCC (Mobile Country Code) — 3 digits identifying the country. For example: 310 for the US, 404/405 for India, 234 for the UK, 505 for Australia.
  • MNC (Mobile Network Code) — 2–3 digits identifying the specific network operator. For example: 260 for T-Mobile US, 840 for Reliance Jio India, 30 for EE UK.
  • MSIN (Mobile Subscription Identification Number) — The remaining digits (up to 10) uniquely identifying the subscriber within that operator's network.

MCC-MNC pairs used

  • AT&T US: 310-410 · T-Mobile US: 310-260 · Verizon US: 311-480
  • Airtel India: 404-20 / 404-45 · Reliance Jio India: 405-840
  • EE UK: 234-30 · Three UK: 234-20
  • Telstra Australia: 505-01
What is the difference between IMSI and IMEI? +
An IMEI identifies the physical handset (the device), while an IMSI identifies the subscriber (the SIM card / user account). If you put a different SIM in the same phone, the IMEI stays the same but the IMSI changes. Both are 15 digits, but only IMEI uses the Luhn checksum.
What is the difference between IMSI and MSISDN? +
The MSISDN is the phone number people dial (e.g. +91 9876543210). The IMSI is an internal network identifier stored on the SIM that is never shared publicly. The two are linked in the operator's Home Location Register (HLR) / Home Subscriber Server (HSS).
What is ICCID and how does it differ from IMSI? +
The ICCID (Integrated Circuit Card Identifier) is a 19–20 digit number that identifies the SIM card itself (the physical chip). The IMSI identifies the subscription profile stored on that SIM. A SIM card can theoretically store multiple IMSI profiles (e.g. dual-SIM-on-one-chip solutions), though this is rarely used in practice.
