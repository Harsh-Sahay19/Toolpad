Test Indian address generator

Test data only

Generate test addresses in the Indian format, with a block, sector or colony, city, state and 6-digit PIN code. Every PIN starts with the real prefix for its state or city. For testing forms, APIs and databases only.

How Indian addresses are structured

A typical Indian postal address has four parts: a house, block or flat number, a locality such as a sector, colony, layout, phase or nagar, the city or town, and the state followed by a 6-digit PIN code. The generator builds addresses in this order, so the output matches the form fields most Indian websites ask for.

The PIN code is the most useful part to get right for testing. Indian PIN codes are six digits. The first digit identifies a postal region, the first two digits identify a sub-region, and the first three digits usually identify a city or district. This generator uses the prefix that belongs to each city, so Delhi addresses start with 110, Bengaluru with 560, Mumbai with 400, Chennai with 600 and Hyderabad with 500.

Locality formats

  • Sector — common in Delhi NCR, Chandigarh and planned cities, for example "Sector 14"
  • Block — used in many government and housing colonies, for example "Block 7"
  • Colony, Nagar, Layout or Phase — used across Karnataka, Telangana, Tamil Nadu and Maharashtra, for example "Phase 3" or "Layout 22"

Why use test Indian addresses in testing?

  • Testing checkout and delivery forms that require a 6-digit PIN code and a state dropdown
  • Validating PIN-to-state or PIN-to-city logic in shipping and serviceability code
  • Seeding Indian e-commerce, logistics, food-delivery or marketplace databases with realistic shipping addresses
  • Creating demo screenshots and sales decks that need believable Indian addresses without using real customer data
  • Load testing address search and autocomplete features with varied locality names

API access

Generate Indian addresses programmatically: GET /api/v1/location/address?country=IN&count=20

Combine an address with GPS coordinates: GET /api/v1/record?country=IN&count=2

Are these real addresses? +
No. Each address is randomly assembled from city names, locality formats and PIN code prefixes. The house number and locality number are random, so the address will not match a real property. Do not use these addresses for deliveries, KYC or any real transaction.
Do the PIN codes match real areas? +
The first three digits match the real postal prefix for each city, which is what most format checks look at. The last three digits are random within a range, so a PIN may not belong to the exact locality named in the address. For tests that need exact PIN-to-locality matching, use an official India Post PIN code directory.
Which states are supported? +
The India option covers Karnataka, Maharashtra, Tamil Nadu, Delhi and Telangana. Each state has three sample cities. The generator does not yet cover all 36 states and union territories.
Can I export the addresses to a spreadsheet? +
Yes. Choose the CSV table view and click Download CSV, or use Download CSV without changing the view. The file includes line1, city, region, postal and country columns, and you can generate up to 50 addresses at a time.
