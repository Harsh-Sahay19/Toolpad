About this test address generator

This tool creates structurally realistic postal addresses. Each one has a valid-format street or locality, a real city name, the correct state or region, and a postal code in the range used by that country. Addresses are randomly assembled and do not correspond to real properties.

Country formats

  • United States: street number, street name and type, city, state abbreviation and a 5-digit ZIP code, for example 221 Maple Street, Austin, TX 78712.
  • India: flat or house number, locality, city, state and a 6-digit PIN code, for example Flat 4B, Rose Garden Layout, Bengaluru, Karnataka 560042.
  • United Kingdom: house number and street, then town and a postcode, for example 12 Station Road, Manchester M4 2AB.

Common uses

  • Testing address fields, validation and autocomplete
  • Seeding e-commerce and logistics databases
  • Demo screenshots and UI mockups
  • Testing mapping and geolocation integrations

Use it from code

Generate addresses through the public API, with no key needed:

GET /api/v1/location/address?country=IN&count=20 GET /api/v1/location/coordinates?country=US&count=10
