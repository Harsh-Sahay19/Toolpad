Test email generator

Test data only

Generate realistic test email addresses for testing forms, APIs, and databases. Choose from multiple styles and domains. Addresses look natural — derived from name patterns, not random strings.

Email address Domain Style

Why use a test email generator?

Using real email addresses in test databases creates privacy risks and potentially triggers real email sends. Test email addresses that follow realistic patterns let you test email validation logic, form submissions, and user registration flows without using real contact information.

Email generation styles

  • firstname.lastname@ — the most common real-world pattern (e.g. [email protected])
  • firstname_lastname@ — underscore separator (e.g. [email protected])
  • initials+lastname@ — first initial + last name (e.g. [email protected])
  • firstname+number@ — name with numeric suffix (e.g. [email protected])

Safe domains for testing

If you want to avoid any chance of real email delivery, use example.com — it is an IANA-reserved domain specifically for documentation and testing purposes. No email sent to @example.com will ever be delivered.

Will emails to these addresses bounce? +
Emails to generated addresses at domains like gmail.com, yahoo.com etc. will likely bounce since the mailboxes don't exist. To guarantee no delivery, use @example.com or @testmail.com addresses — these domains are specifically designated for testing.
Do generated emails pass email validation? +
Yes — all generated addresses are syntactically valid RFC 5322 email addresses. They will pass format validation checks (regex patterns, HTML5 email input validation). They will not pass deliverability checks (MX record verification or mailbox existence checks).

Choosing a domain

The generator defaults to the reserved example domains, such as example.com. These domains are set aside for documentation and testing, so a generated address cannot reach a real mailbox. Use them for signup forms, validation rules and database fixtures. Avoid real domains, because test emails sent to them can reach real people.
