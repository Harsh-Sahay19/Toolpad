How it is calculated

Each instalment is invested at the start of the month, so the formula is that of an annuity due:

FV = P × ((1 + i)^n − 1) ÷ i × (1 + i) P = monthly investment i = annual return ÷ 12 ÷ 100 n = years × 12

If the return is 0, the value is simply P × n. Figures are rounded to the nearest whole unit of the selected currency.

Questions

A systematic investment plan (SIP) is a way to invest a fixed amount at regular intervals, usually monthly, into a fund. Regular investing spreads your purchases over time.
The calculator assumes one fixed return for the whole period. Real markets move up and down, so actual results will differ. Treat the figure as an illustration of compounding, not a forecast.

Using the estimate

Enter the monthly amount, the expected annual return and the number of years. The result separates the money you put in from the growth. A higher return or a longer period increases growth more than a larger monthly amount does, because the returns themselves earn returns. Try a lower return rate as well, so you can see how sensitive the result is to the assumption.
