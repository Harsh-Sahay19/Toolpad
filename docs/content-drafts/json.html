What this JSON formatter does

The JSON formatter checks JSON text, prettifies it with indentation, or minifies it into one line. When the JSON is invalid, it reports the error with its line number, so you can find the mistake quickly. Everything runs in your browser.

How to use it

  1. Paste your JSON into the input box.
  2. Click Prettify JSON to indent it, Minify to remove whitespace, or Validate only to check it without changing it.
  3. Copy or download the result, or clear the box to start again.

Common JSON errors

  • Trailing commas: JSON does not allow a comma after the last item in an object or array.
  • Single quotes: JSON strings must use double quotes.
  • Unquoted keys: every key must be a quoted string.
  • Comments: JSON has no comment syntax, so remove // and /* */ comments before validating.

Formatting, minifying and validating

Prettifying changes only whitespace, so the data is the same before and after. Minifying removes the whitespace, which makes the payload smaller for APIs and config files. Validating checks the syntax against the JSON standard (RFC 8259). It does not check the data against a schema, so a valid document can still have the wrong fields.

Privacy

JSON you paste is processed in your browser. It is not stored or sent to Toolpad's servers. Remove sensitive values such as tokens and passwords before you share a formatted result with anyone.
