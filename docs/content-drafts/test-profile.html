What this profile generator does

The generator creates a complete test person: a name, username, email address, phone number, postal address and date of birth, all in a consistent format for the chosen country. Use it to fill a test user table, to seed a sign-up flow, or to build demo accounts. You can generate several at once and export them as a CSV.

How to use it

  1. Choose the country or region.
  2. Choose how many profiles you need.
  3. Click Generate, then copy or download the results.

What a profile is made of

  • Name and username: a name from the regional pools, and a username built from it.
  • Email: a name-based address on a reserved example domain (example.com, example.org or example.net). These domains are set aside for documentation and testing, so they do not belong to real mailboxes.
  • Phone: a number in the country's format.
  • Address: a postal address for the same country, from the address generator's formats.
  • Date of birth: a random date that makes the person between 18 and 65 years old, useful for age-check logic.

The parts are generated separately and then combined, so a profile is consistent in format but is not a record of any real person.

Limits and responsible use

  • A generated profile does not describe a real person. Any match with a real individual is coincidental.
  • Do not use generated profiles to open accounts, claim services or submit forms in anyone's name.
  • Do not send mail to generated addresses from a real mail service. For mail testing, use the test email generator with its example.com option.
  • Keep test data separate from real customer data, and remove it when a test is finished.

For the parts on their own, see the test name generator, the test address generator, the test email generator and the phone number generator.
