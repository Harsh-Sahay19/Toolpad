What this UUID generator does

The generator creates RFC 4122 UUIDs, which are 128-bit identifiers written as 36 characters in five groups separated by hyphens. You can generate version 4 (random) or version 1 (time-based), in batches of up to 1000, and copy them or download them as a CSV.

How to use it

  1. Choose the UUID version.
  2. Choose how many UUIDs to generate.
  3. Click Generate, then copy the list or download the CSV.

UUID version 4 and version 1

  • Version 4 fills almost all of its 128 bits with random values. The version and variant bits are fixed. It is the most common choice for IDs in application data, because it needs no coordination and reveals nothing about when or where it was made.
  • Version 1 combines a timestamp with a node identifier. The timestamp part makes version 1 values sortable by time, but the node part can expose the machine's network address. Use version 4 when that matters.

Collisions between random version 4 values are so unlikely that most systems treat them as unique without checking. For database primary keys, consider whether time-ordered identifiers would suit your indexes better; this tool does not generate those.

Common uses and limits

  • Seeding database tables and fixtures with unique keys.
  • Testing API request and response handling with realistic identifiers.
  • Creating sample records for demos and documentation.

A UUID proves nothing about the person or device behind it. Generated values are not tied to any account or record. Do not use them as passwords, session secrets or security tokens; use a cryptographic random source for those.
